# FireMind Runtime Media

These files were captured from the FireMind APK installed on an Android TV 10 x86 emulator through ADB. The emulator used software CPU emulation because the sandbox does not expose KVM acceleration.

The PNG files are direct runtime screenshots. `firemind-demo.mp4` is a direct screen recording of the Home → Recommendations → Details path. `firemind-clean-demo-final.mp4` is a direct clean-state screen recording of the Details and saved-state transition. `firemind-evidence.mp4` combines the direct screen recording with the direct Watchlist screenshot as a short evidence reel so the final saved-title state is visible in one file.

This media proves compatible Android TV behavior. It does not prove physical Fire TV hardware behavior.
